## Untested card classes / Denenmemiş kart sınıfları
`kur.ps1` picks the engine from `scripts/kart_tablosu.json`. These classes have no run reported (or only a partial one); every line is a reading of a document or a guess, there is no measured number. A PR that adds a run (see the README box "Add your card") turns a line into a row of the table above. / `kur.ps1` motoru `scripts/kart_tablosu.json`'dan seçer. Bu sınıflar için bildirilmiş koşu yoktur (ya da kısmidir); her satır bir belgeyi okumak ya da tahmindir, ölçülmüş sayı yoktur. Bir koşu ekleyen PR (README'deki "Kartınızı ekleyin" kutusu) satırı yukarıdaki tablonun satırına çevirir.
